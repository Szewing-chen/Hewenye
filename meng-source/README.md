# 轩 · 梦

轩的个人主页。手机上铺满屏幕，平板上是居中的宽栏。封面、头像、分栏和图片灯箱都在，文字、照片和链接来自她自己的资料《梦》。手机上可以左右滑动看大图，分享按钮会唤起系统分享。

四个分栏：

- 相识：鹤闻野、常驻与通关
- 相知：角色、建模、雾山影在职
- 相惜：话术、板赠、头牌卡，以及原文链接
- 须知：虚恋须知、约前说明、陪评口令

打开页面会在资料页里循环播放 aayuyuu 的《Lazy Type Beat》，不用跳去网易云。封面是原来的水洼倒影。排单表、话术、板赠和头牌卡会打开原来的金山文档。

## 本地运行

```bash
npm install
npm run dev
```

开发服务器默认端口是 3000。本仓库在预览环境里使用 38421：

```bash
npx next dev --turbopack -H 0.0.0.0 -p 38421
```
